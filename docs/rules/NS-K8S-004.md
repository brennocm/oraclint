# NS-K8S-004: Operator UI exposed by a Kubernetes Service

| Severity | Target | Status | CWE |
|---|---|---|---|
| high | k8s | stable | CWE-668 |

## Description

Fires for every port of a `Service` of type `LoadBalancer` or `NodePort`
whose `port` or numeric `targetPort` is `6688` or `6689` (the node's default
HTTP and HTTPS ports). Named target ports are not resolved.

## Why it matters

`LoadBalancer` and `NodePort` Services make the port reachable from outside
the cluster, usually from the internet. The operator UI and API should only be
reachable by operators, for example through `kubectl port-forward`, a VPN or
an authenticated ingress restricted to them.

## Vulnerable example

```yaml
kind: Service
spec:
  type: LoadBalancer
  ports:
    - port: 6688
```

## Fixed example

```yaml
kind: Service
spec:
  type: ClusterIP
  ports:
    - port: 6688
```
